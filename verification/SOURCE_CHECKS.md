## Calculation checks

- Separate scheduled domestic traffic from international and non-scheduled services; require unique airline-month keys.
- Check both comparison windows contain 12 observations for every airline; sum passengers/RPK/ASK before calculating shares and load factors.
- Retain unrounded values through each calculation. Percentage changes and percentage-point differences are separate fields.
- Check all four revenue/PAT input pairs appear in their cited reports. Financial inputs are company-wide and are never divided by domestic-only traffic.
- Verify each break-even scenario closes the initial accounting loss under its stated contribution assumption. Contribution rates are assumed, not estimated; no cash runway is reported.
- The earlier national 5% share threshold remains in background calculations. The revised case study uses route frequencies for local significance. Treat Akasa's follow-up as ending at the observation cutoff.

The same checks can be rerun from the repository root:

```bash
python3 calculate.py
python3 verify.py
```

The verifier uses saved PDF text/OCR extracts and rechecks the new HTML passages directly in the downloaded originals; visual review remains a separate step. The updated run passed **17 document fingerprints, 65 source terms, 108 original DGCA cells, four financial rows and four scenario equations**, alongside the route checks below. [Machine-readable check results](verification_results.json) record what passed. These checks verify source content and arithmetic, not a causal explanation of airline outcomes.

## Standalone repository reproduction

The repository includes the full **228-PDF schedule archive**, the complete saved extraction, its parser and all other analysis inputs. The 102 PDFs above are the publications supporting the O3 route evidence; the larger archive also includes unused and unsupported historical formats. [Archive manifest](../data/routes/full_schedule_archive/source_manifest.json).

`python3 reproduce.py` runs entirely offline with the Python standard library. It rebuilds major-route selection, flight counts, shares, HHI and coverage before the O3 calculations. All **20 route ranks, 1,114 route-months, 5,519 airline shares and 2,780 coverage records** are compared with the pinned reference snapshots. The regional and worked-example rows are checked against the full extraction. All source files and saved inputs have an additional [fingerprint manifest](reproduction_inputs.json).

`python3 reproduce.py --from-pdfs` first regenerates the full extraction with Poppler's `pdftotext`, then performs the same checks. The original closure replies and verified official merger passages needed by the route conventions are included under `sources/`. [Reproduction check results](reproduction_results.json) also check the headline numerical figures and portable document links. The workflow reproduces the evidence supporting the qualitative conclusions; it does not turn those arguments into causal estimates.

An isolated copy containing no previous `results/` directory and no surrounding economics-project files was run with `--from-pdfs`. All 228 PDFs were re-extracted into 189,980 movement rows; the pinned inputs matched, and every regenerated result file was byte-identical to the default workflow. [Standalone-run record](standalone_run.json). The checked extraction used Poppler 26.04.0.
